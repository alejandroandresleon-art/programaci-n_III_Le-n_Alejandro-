## 📖 Descripción

Repositorio correspondiente a la materia **Programación III**, donde se recopilarán ejercicios, prácticas, proyectos y conocimientos desarrollados durante el curso.

A lo largo de la materia se trabajarán diferentes tecnologías y herramientas fundamentales para el desarrollo web moderno, desde la estructura y estilos de una página hasta la creación de aplicaciones completas utilizando frameworks y lenguajes modernos.

---

## 🧠 Tecnologías y conceptos

### 🌐 HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de las páginas web. Permite definir elementos como títulos, párrafos, enlaces, imágenes, formularios, tablas y demás componentes de una página.

---

### 🎨 CSS

**CSS (Cascading Style Sheets)** permite aplicar estilos y diseños a los documentos HTML. Se utilizará para trabajar aspectos como colores, tipografías, distribución, tamaños, animaciones y diseño responsive.

---

### ⚡ JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento dinámico a las aplicaciones web. Permite manipular el DOM, gestionar eventos, consumir APIs y desarrollar lógica del lado del cliente.

---

### 🔷 TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y otras características que facilitan la creación y mantenimiento de aplicaciones grandes y escalables.

---

### 🦁 NestJS

**NestJS** es un framework para desarrollar aplicaciones backend utilizando **Node.js y TypeScript**. Permite crear APIs y aplicaciones del lado del servidor mediante una arquitectura organizada y modular.

---

### ⚛️ ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para construir interfaces de usuario. Está basada en componentes reutilizables y permite desarrollar aplicaciones web modernas, dinámicas e interactivas.

---
